# StackAlign

A standalone Bash-based LEMP installer and manager for supported EL-family Linux systems on x86_64.

## Project status

**M2a tuning engine implemented; CI passed on AlmaLinux 9 and Ubuntu 24.04.**

- `lib/tune.sh` implements the lean and standard arithmetic paths specified by `docs/TUNING.md`.
- `tests/test_tune_math.py` contains T1–T28, including the two pinned arithmetic floors (T27 = 391 MiB, T28 = 3389 MiB).
- CI matrix: AlmaLinux 9 (lint + test) and Ubuntu 24.04 (lint + test). [Latest green run](https://github.com/ljrseals-dev/StackAlign/actions/runs/43251330070).
- The M2a tuning contract documentation is included in [PR #1](https://github.com/ljrseals-dev/StackAlign/pull/1) and awaits merge to `main`.

## What is not yet done

- `lib/tune.sh` treats `SA_PHP_CHILD_MIB` and the fixed service costs as **assumptions, unmeasured**. M2b replaces them with measurements on real hosts.
- The 512 MiB no-swap floor is verified arithmetically (T3: 1 child, 48 MiB buffer). It has not been load-tested on a real 512 MiB VM.
- Isolation, backup, routines, WordPress hardening, and the remaining LEMP modules are designed but not implemented.
- No sizing table is published. Tables are generated by running `lib/tune.sh`, never typed by hand.

## Scope

StackAlign manages a LEMP server stack and supported self-hosted PHP application workloads. X-Cart 5.6 is a warning-only workload profile — not an installation target. Hosted SaaS and non-LEMP application domains are excluded.

## Operating principles

- Bash for the installer and runtime. Python only for tests and benchmarks.
- EL-family x86_64. Ubuntu 24.04 is supported as a CI target only.
- No unattended update application.
- No secrets in repository, logs, snapshots, or history.
- No telemetry.
- No unmeasured performance, memory, or recovery-time claims.
- Sizing formulas live only in `docs/TUNING.md`.

## Development

Feature branches, pull requests, `main` preserved. A merge is not evidence of a successful build — CI green on the target platform is.
